## Что такое Gelancha

Gelancha — сервис, который соединяет тех, кому нужно что-то доставить, с
курьерами поблизости. Заказчик оформляет заявку в приложении, сервис
рассчитывает цену и находит курьера, курьер забирает и привозит.

Сервис работает в г. Грозном.

Оператор сервиса — ИП Шихабов Расул Рухаевич (ИНН 720500526379). Сервис
является информационной площадкой; доставку выполняет курьер лично
(см. [публичную оферту](oferta.html)).

## Для заказчиков

### Доставка

Курьер забирает отправление по одному адресу и передаёт получателю по
другому. Подходит для документов, продуктов, небольших посылок и крупных
вещей, которые помещаются в легковой автомобиль.

### Покупка и доставка

Заказчик составляет список покупок, курьер покупает товары в указанном
магазине, присылает фактические цены и чек, затем привозит покупки.
Рецептурные лекарства, алкоголь и табак не покупаются и не доставляются.

### Как формируется цена доставки

Цену считает сервис и показывает её **до** подтверждения заказа. Цена
складывается из:

| Составляющая | Значение |
|---|---|
| Подача | [ЗАПОЛНИТЬ: 100 ₽ — сейчас стоит плейсхолдер] |
| За километр маршрута | [ЗАПОЛНИТЬ: 15 ₽ — плейсхолдер] |
| За минуту в пути | [ЗАПОЛНИТЬ: 3 ₽ — плейсхолдер] |
| Минимальная стоимость заказа | [ЗАПОЛНИТЬ: 200 ₽ — плейсхолдер] |
| Надбавка за тип груза | документы, продукты, небольшая посылка, крупный груз — [ЗАПОЛНИТЬ: сейчас 0 ₽ для всех] |
| Ночной коэффициент | ×1,2 с 00:00 до 09:00 по времени Грозного (МСК) [ПРОВЕРИТЬ: если ночь задумана как 21:00–06:00, нужна правка кода, см. README] |
| Повышенный спрос / зона | коэффициент показывается в цене заказа, если действует |

Отмена заказа заказчиком бесплатна. Стоимость покупаемых товаров
оплачивается отдельно, по чеку магазина.

### Как оплатить

Заказчик платит **курьеру напрямую**:
- наличными при получении;
- переводом по СБП на номер курьера, который показывается в заказе.

Деньги заказчика через сервис и через ЮKassa не проходят.

## Для курьеров

### Доступ к заказам

Сервис бесплатно показывает курьеру заказы поблизости, маршрут и
контакты. За каждый выполненный заказ с баланса курьера списывается
комиссия сервиса.

| Услуга | Цена |
|---|---|
| Комиссия сервиса с выполненного заказа | [ЗАПОЛНИТЬ: сейчас 0 % для всех курьеров] от стоимости доставки; индивидуальная ставка, если назначена, показывается в приложении до принятия заказа |
| Минимальное пополнение баланса | 200 ₽ |
| Возврат неиспользованного остатка по заявлению | бесплатно, до 10 календарных дней |
| Мгновенный вывод остатка по СБП | 2,8 % от суммы вывода |
| Вывод наличными раз в неделю | бесплатно |

### Как пополнить баланс

В приложении: «Баланс» → «Пополнить» → сумма → оплата по СБП через ЮKassa.
Деньги зачисляются после подтверждения платежа банком. Чек по 54-ФЗ
приходит в электронном виде.

## Безопасность платежей

Пополнение баланса принимается через платёжный сервис ЮKassa
(ООО НКО «ЮМани», лицензия Банка России). Оплата производится по Системе
быстрых платежей в приложении вашего банка. Данные банковских карт и
доступы к банку сервис Gelancha не получает и не хранит.
