# Юридические документы Gelancha

Источник правды для страниц сайта `gelancha.ru/docs/*` и для ссылок из
приложения (`src/constants/legal.ts`). Страницы сайта делаются из этих
файлов, а не переписываются заново.

Документы — рабочая основа. До публикации их должен проверить юрист.

## Состав

| Файл | Страница на сайте | Что это |
|---|---|---|
| `oferta.md` | `/docs/oferta.html` | Публичная оферта, v1.1 |
| `uslugi-i-tarify.md` | `/docs/tarify.html` | Описание услуг и цены |
| `vozvrat.md` | `/docs/vozvrat.html` | Правила отмены и возврата денег |
| `kontakty-i-rekvizity.md` | `/docs/kontakty.html` | Контакты и реквизиты ИП |
| `politika-personalnyh-dannyh.md` | `/docs/politika.html` | Политика по 152-ФЗ, v1.1 |
| `soglasie-na-obrabotku.md` | `/docs/soglasie.html` | Согласие на обработку ПДн, v1.1 |

## Что ЮKassa проверяет на сайте перед боевым подключением

| Требование | Где закрыто |
|---|---|
| Описание услуг, за которые принимается оплата | `uslugi-i-tarify.md` |
| Цены в рублях | `uslugi-i-tarify.md` — после заполнения плейсхолдеров |
| Порядок оплаты | `oferta.md` разд. 4–5, `uslugi-i-tarify.md` |
| Условия возврата | `vozvrat.md` |
| Публичная оферта | `oferta.md` |
| Политика конфиденциальности | `politika-personalnyh-dannyh.md` |
| ФИО ИП, ИНН, ОГРНИП, адрес, телефон, почта | `kontakty-i-rekvizity.md`, футер сайта |
| Документы доступны с любой страницы | ссылки в футере сайта — задача лендинга |
| Сайт открывается, работает HTTPS, нет «в разработке» | задача лендинга |

## Что заполнить владельцу (`[ЗАПОЛНИТЬ: …]`)

1. Даты публикации всех документов.
2. Тарифы доставки: подача, км, минута, минимум, надбавки за груз. В
   `pricing_rules` сейчас стоят значения с пометкой «плейсхолдер §6».
3. Ставка комиссии для курьеров. Сейчас глобальная 0 % (R53). На сайте
   нужно указать фактическую.
4. Города обслуживания.
5. Часы работы поддержки.
6. Где и когда курьерам выдаются наличные при еженедельном выводе.
7. Какой ИИ-провайдер реально включён на сервере. Остальных убрать из
   политики.
8. Использует ли сайт cookie и веб-аналитику.
9. Почтовый адрес, если он отличается от адреса регистрации.

## Что исправлено против версии 1.0

- **Расчёты в оферте не совпадали с кодом.** Версия 1.0 говорила, что
  Владелец принимает оплату по СБП «как платёжный агент Курьера» и
  возвращает её сам. В коде клиент платит курьеру напрямую (миграция 0075,
  подтверждено владельцем 2026-10-08), через ЮKassa идёт только пополнение
  баланса курьера (`billing/yookassa.ts`). Кроме того, ИП не зарегистрирован
  платёжным агентом по 103-ФЗ. Оферта переписана под фактическую схему.
- **Что продаётся через ЮKassa, раньше не было описано.** Добавлено:
  пополнение баланса — аванс за услугу доступа к заказам, возврат
  неиспользованного остатка, чек по 54-ФЗ.
- **Политика не называла часть внешних сервисов**, которые вызывает
  сервер: DaData, OpenRouteService (Германия), Яндекс SpeechKit, 2ГИС, Expo
  push (США), ИИ-провайдеры (США/КНР). Добавлены, и добавлен раздел о
  трансграничной передаче.
- **Срок ответа на обращения по ПДн** был «до 30 дней». По ст. 14 и 20
  152-ФЗ с 01.09.2022 — 10 рабочих дней. Исправлено.
- **Одна отметка «принимаю оферту и даю согласие».** С 01.09.2025 согласие
  на обработку ПДн оформляется отдельно от других документов. В
  `soglasie-na-obrabotku.md` описаны две отметки; экран
  `src/app/(auth)/role.tsx` пока показывает одну.
- **Банк в реквизитах** — АО «Тинькофф Банк» переименован в АО «ТБанк»
  в 2024 г. БИК прежний. Добавлен корр. счёт; сверить с выпиской.

## Открытые вопросы, которые документы не решают

1. **Чек клиенту по 54-ФЗ.** Владелец на УСН, клиент платит курьеру
   напрямую. Кто и какой чек выдаёт клиенту, не решено (CLAUDE.md, «Решения
   владельца»). В оферте п. 4.3 помечено `[ПРОВЕРИТЬ]`.
2. **Хранение денег курьеров на балансе и выплата бонусов.** Баланс, который
   можно вывести обратно, вместе с бонусами похож на учёт чужих денег. Нужна
   оценка юриста, не требуется ли иная схема (агентский договор, «Безопасная
   сделка» ЮKassa).
3. **Комиссия 2,8 % за мгновенный вывод аванса** для курьеров-физлиц.
   В `vozvrat.md` возврат по заявлению сделан бесплатным, мгновенный вывод
   описан как отдельная услуга. Юрист должен подтвердить.
4. **Хостинг в Ирландии.** Нарушение ч. 5 ст. 18 152-ФЗ, пока данные
   граждан РФ хранятся за рубежом. Переезд запланирован до первого живого
   пользователя.
5. **Ночной коэффициент.** `isNight()` в `_shared/pricing.ts` считает ночь
   как 21:00–06:00 **UTC**. В Ишиме (UTC+5) это 02:00–11:00 местного
   времени. Если имелась в виду местная ночь, это ошибка в коде. В тарифах
   часы оставлены под `[ПРОВЕРИТЬ]`.
6. **Объявленная ценность** (оферта п. 10.2) в приложении не реализована.
7. **Срок хранения геотреков 5 лет** избыточен для заявленных целей.
8. **Уведомления в Роскомнадзор** — об обработке ПДн и о трансграничной
   передаче — подаёт владелец до запуска.

## После изменения документов

- Поднять версию в заголовке файла.
- При изменении согласия — поднять `Legal.version` в
  `src/constants/legal.ts`, чтобы было видно, кто на какую редакцию
  согласился.
